# 🚨 개발자 비상근무

비상 상황을 대비하여 월별 비상근무표 자동화를 위한 **'비상근무표 생성 프로그램'** 을 만든다.

## 구현할 기능

### 입출력
- [ ] 월과 시작 요일을 입력받는다.
- [ ] 평일 순번과 휴일 순번의 값을 입력받는다. (입력 값이 올바르지 않은 경우 평일 순번부터 다시 입력받는다.)
- [ ] 평일이면서 공휴일이면 날짜 뒤에 `(휴일)`을 출력한다.
- [ ] 비상근무표 출력을 완료하면 프로그램을 종료한다.

### 달력
- [ ] 입력된 월과 요일에 맞춰 날짜를 계산한다. (2월은 28일까지)
  (`01-01, 03-01, 05-05, 06-06, 08-15, 10-03, 10-09, 12-25` 는 공휴일)
- [x] 일수를 입력하면 요일 목록을 반환한다.

### 비상근무자 배정
- [ ] 입력받은 순번에 따라 근무자를 배정한다.
- [ ] 비상 근무자가 연속 2일 근무하게 될 경우, 다음 순번자와 순서를 바꾼다.

### 에러 메시지
- [x] 공통: 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`를 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 입력을 다시 받는다.
- [ ] 월이 숫자가 아닌 경우, 1 ~ 12 사이가 아닌 경우.
- [ ] 시작 요일이 '월 ~ 일'이 아닌 경우.
- [ ] 같은 근무자가 평일 순번 혹은 휴일 순번에 2번 이상 입력된 경우.
- [x] 근무자의 이름이 5자를 초과하는 경우.
- [ ] 입력된 근무자가 5명 미만이거나 35명을 초과하는 경우.
